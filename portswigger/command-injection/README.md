# OS Command Injection

Write-ups and solutions for OS command injection labs from PortSwigger Web Security Academy.

## Topics

* Command Injection Fundamentals
* Detecting Command Injection
* Executing Arbitrary Commands
* Blind Command Injection
* Time-Based Detection
* Output Redirection
* Out-of-Band Techniques
* Filter Bypasses
* Prevention and Mitigation

## Purpose

Document lab solutions, command injection techniques, detection methods, exploitation approaches, and key takeaways to develop a deeper understanding of operating system command injection vulnerabilities.
