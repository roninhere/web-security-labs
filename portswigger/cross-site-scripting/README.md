# Cross-Site Scripting (XSS)

Write-ups and solutions for cross-site scripting labs from PortSwigger Web Security Academy.

## Topics

* Reflected XSS
* Stored XSS
* DOM-Based XSS
* HTML and JavaScript Contexts
* XSS in Different Contexts
* Filter Bypasses
* Content Security Policy (CSP)
* XSS Prevention

## Purpose

Document lab solutions, injection contexts, payload construction, filter bypass techniques, and key takeaways to develop a deeper understanding of cross-site scripting vulnerabilities.
